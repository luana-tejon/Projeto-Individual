## 🌟 Visão Geral

Memory Cartoon Nostalgia é um projeto criado para trazer de volta a nostalgia dos desenhos animados que marcaram a infância de milhões de pessoas.
A proposta é simples e poderosa: ao jogar o jogo da memória, os usuários reencontram personagens icônicos dos maiores estúdios de animação do mundo — como Disney, DreamWorks, Fox, Sony, 20th Century Studios, Pixar e Cartoon Network.

Cada carta revelada carrega um impacto emocional: aquele momento de ver “ahhh, eu lembro desse desenho!”.
Esse é o coração do projeto: resgatar memórias afetivas através da experiência interativa.

## 💛 Despertar nostalgia

Ao mostrar personagens clássicos, o jogo busca reconectar o jogador com lembranças da infância — sessões de filmes, tardes no sofá, momentos em família, risadas e emoções.

## 🕹️ Como o Jogo Funciona

O jogo segue a lógica clássica do memory game, mas com um toque de emoção visual.

## ✔️ Regras e Mecânica

O jogador vê várias cartas viradas para baixo.

Cada carta esconde um personagem de um dos estúdios.

Ao clicar, a carta vira e mostra a imagem.

O jogador deve encontrar pares iguais.

A cada acerto, surge aquele momento de nostalgia com personagens conhecidos.

O jogo segue até que todos os pares sejam encontrados.

## ✔️ Objetivo final

Finalizar o jogo descobrindo todos os pares, enquanto revive memórias dos desenhos que marcaram sua vida.

## ✔️ Publico alvo

Pessoas que gostam de jogos leves e rápidos.
